# Corrigir posicao do HUD

Se os textos aparecerem no centro do ecra, adiciona o componente `HudLayoutBootstrap` ao objeto `HUDCanvas`.

## Ligacoes

Arrasta:

- `ObjectiveText` para `objectiveText`
- `PlaqueText` para `plaqueText`
- `StatusText` para `statusText`

O script ajusta automaticamente o HUD para o canto superior esquerdo.

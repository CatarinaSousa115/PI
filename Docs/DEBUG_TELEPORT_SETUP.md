# Teleporte de debug entre salas

Usa o componente `DebugRoomTeleporter` no `Player` para testar as salas sem portas.

## Como configurar

1. Criar 5 objetos vazios na cena:
   - `TP_Lobby`
   - `TP_Sala2`
   - `TP_Sala3`
   - `TP_Sala4`
   - `TP_Sala5`
2. Colocar cada um no centro da respetiva sala, com `Y = 1`.
3. Adicionar `DebugRoomTeleporter` ao `Player`.
4. Ligar os 5 pontos ao script.

## Teclas

- `1`: Lobby
- `2`: Sala 2
- `3`: Sala 3
- `4`: Sala 4
- `5`: Sala 5
